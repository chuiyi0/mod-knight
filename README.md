# 《魔改骑士 · Mod Knight》

一款受《元气骑士》启发、面向安卓手机与 PC 浏览器的**复古像素奇幻地牢 Roguelike 动作射击游戏**——纯单机离线、零氪无广告，架构预留 Wi-Fi 局域网双人联机接口。

## 核心特色

- **横屏极简元气手感**：左手浮动摇杆 + 自动锁敌，右手仅「攻击/互动、技能、切枪」，自动回盾 + 破盾保护 + 近战切碎/反弹子弹 + 掩体拉扯。
- **37 把脑洞武器 × 24 张魔改贴纸**：超级咸鱼、高压电蚊拍、40米大长刀、折凳（贴纸威力+20%）、键盘侠圣经、尖叫橡胶鸡、一拳手套、黄金平底锅（背在背后防弹）+ 追踪/分裂/激光化/巨化/下蛋母鸡/变小黄鸭/核爆/武器影分身/混沌随机贴纸，任意排列组合！
- **完整 3 大关 × 5 层（6 大随机双生态）+ 无尽深渊 4-1+**：哥布林遗迹、霜雪古堡、骷髅地穴、炼金工坊、火山魔殿、星界虚空，6 位关底 Boss + 隐藏裂纹密室彩蛋 Boss「物业经理·大鹅王」。
- **16 种高密度奇遇房**：贴纸工坊、命运老虎机、可攻击硬抢的黑心奸商、恶魔诅咒祭坛、许愿池、重铸铁匠、回收机器人、6 种远古雕像、红蓝赌命宝箱怪、命运转盘、雇佣兵酒馆、怪医诊所、竞技场、天赋附魔师、武器收藏家、赏金黄金史莱姆裂隙。
- **可自由走动的豪华像素客厅**：6 位英雄（Lv.1~Lv.7 升级）、6 只功能宠物、蓝币扭蛋机、武器锻造台、贴纸预印台、6 块魔法花园（8 种植物，双成熟机制）、每日挑战因子看板、地下室图鉴与成就、离线存档码导入导出。

## 本地运行与测试

```bash
npm install
npm run dev      # 启动本地与局域网服务（手机连同 Wi-Fi 打开局域网地址即可横屏实测）
npm run typecheck
npm test
npm run build
```

## 获取安卓 APK

推送至 GitHub 后，`.github/workflows/build-android-apk.yml` 会自动通过 Capacitor 编译生成 `mod-knight-debug.apk`，在仓库 **Actions → Build Mod Knight Android APK → Artifacts** 中一键下载即可安装到安卓手机！
