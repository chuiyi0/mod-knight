### 1.2 六大武器分类
1. **近战冷兵器**（0~2 耗蓝）：挥砍可切碎敌方普通子弹，保命神器；贴上弹道类贴纸后，挥砍同时可发射剑气/激光/追踪弹！
2. **热兵器/枪械**（1~5 耗蓝）：射速快、弹道直、吃暴击和分裂贴纸，奇幻地牢里的“降维打击”。
3. **魔法法杖/法书**（2~8 耗蓝）：弹幕华丽、带追踪或范围元素效果，与元素贴纸相性极佳。
4. **弓箭/蓄力重炮**（2~10 耗蓝）：长按蓄力放大伤害、穿透与暴击，蓄满一发入魂。
5. **无厘头奇物/日常杂物**（0~6 耗蓝）：反差感与节目效果担当（咸鱼、马桶搋子、电蚊拍、尖叫鸡、外卖炸弹等）。
6. **Boss 专属红武**（机制特化）：每个关底 Boss 和隐藏 Boss 的招牌武器。

## 3. 招牌核心机制：魔改贴纸系统（24 张）

> **核心理念**：武器决定“基础形态与手感”，贴纸决定“离谱变异与构筑上限”。所有贴纸均采用**统一管线（Attack Pipeline Hook）**生效，确保**无论给近战、枪械还是奇物贴上，都能产生合理且搞笑的化学反应**！

### 3.1 贴纸获取与操作规则
1. **获取渠道**：贴纸工坊（奇遇房）、绿色/金色贴纸礼盒、商店购买、Boss 必掉 1 张稀有以上贴纸、老虎机大奖、隐藏密室。
2. **粘贴操作**：捡到贴纸时弹出轻量浮窗（不遮挡战斗，可暂停细看），一键选择贴到「主武器」或「副武器」，或者直接「分解成 25 金币」。
3. **覆写与剥离**：
   - 武器槽位贴满后，新贴纸可以覆盖旧贴纸（旧贴纸销毁），或在【贴纸工坊】花少量金币将已有贴纸**无损撕下并转移**到新武器上。
   - **同种贴纸默认不可重复贴在同一把武器上**（防止简单堆叠破坏数值，鼓励不同种类组合出花样！仅“无尽深渊”解除部分限制）。
4. **近战武器兼容铁律**：当给**近战武器**（如咸鱼、折凳、电蚊拍）贴上【弹道变异类】贴纸（如激光化、多重分裂、自动追踪）时，近战挥砍依然保留砍子弹能力，同时**每次挥砍都会向前发射一道对应贴纸的剑气/激光/追踪鱼影**，彻底打破近战与远程的边界！

## 4. 经典“离谱化学反应”组合示例（Design Validation）

为了验证贴纸管线的化学反应是否真的好玩，以下是玩家在实战中可以轻松整出来的代表性构筑：

1. **「全自动烤鱼光线」**：`超级咸鱼` + `激光化改装贴` + `自动拐弯贴纸` + `爆裂辣椒贴`
   - 效果：每挥一下咸鱼，既砍掉面前子弹，又射出一道拐弯追着怪烧的冰火烤鱼激光！
2. **「养鸡场加特林」**：`地精转轮加特林` + `下蛋母鸡贴` + `鬼畜射速贴` + `节能环保贴`
   - 效果：0 蓝耗疯狂突突，3 秒钟在 Boss 房间铺满 20 只暴走自爆鸡，画面离谱到笑出眼泪。
3. **「零元购钞能力」**：`钞能力散钱枪` + `撒币打赏贴` + `一分三分裂贴纸`
   - 效果：打出去花 1 块钱，打死怪掉 4 块钱，越打越有钱，越花越痛！
4. **「超级巨化折凳」**：`折凳（白板）` + `超级巨化贴纸` + `武器影分身贴` + `核能辐射贴`

## 5. 防崩坏与性能保底规则（工程必看）

脑洞和爽感不能以“手机卡成 PPT”或“一秒秒杀毫无游戏性”为代价，因此设立 4 条硬性底线：
1. **同屏弹幕与召唤物对象池上限**：
   - 玩家子弹同屏上限 `180` 发（超出时优先合并伤害至最新子弹并放大尺寸，既不丢 DPS 又不卡帧）；
   - 暴走鸡/骷髅/史莱姆等召唤物同屏上限 `16` 只（超出时最早的召唤物立即冲锋自爆）。
2. **动态透明度保护**：当玩家同屏弹幕超过 `40` 发时，玩家子弹透明度自动渐变降至 `55%`，而敌方弹幕始终保持 `100%` 不透明高亮描边，保证永远看得清躲得开。
3. **Boss 控制递减（防无限控死）**：冰冻、眩晕、变鸭子等强控对 Boss 的持续时间缩减为 30%（变鸭子对 Boss 改为“头顶冒出小鸭子帽子并降低 20% 移速”，保留笑点但不破坏 Boss 战），且连续控制有 5 秒递减保护。
4. **贴纸蓝耗平衡**：强力变态贴纸通常伴随 `+1~+3` 蓝耗，倒逼玩家要么搭配【节能环保贴】/【击杀回蓝】/【蓝量武器】，要么用高蓝耗神兵打爆发 + 0 蓝耗近战清杂兵，让「切枪键」始终有战略价值！
